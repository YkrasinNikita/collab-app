# CollabApp — совместное редактирование заметок и ментальных карт

Веб-приложение с микросервисной архитектурой, позволяющее пользователям создавать заметки и ментальные карты, приглашать других пользователей для совместной работы, комментировать документы, управлять правами доступа и работать в реальном времени.

## Технологии

### Фронтенд
- Next.js 14 (React 18)
- TypeScript
- Tailwind CSS
- React Flow
- Socket.IO Client

### Бэкенд
- Node.js
- Express
- MongoDB (Mongoose)
- JWT (Access + Refresh Tokens)
- Socket.IO
- Pino (логгер)

### Инфраструктура
- Docker
- Docker Compose
- Микросервисы (`auth`, `documents`, `collaboration`)
- Git

## Требования

- Docker Desktop (или Docker Engine + Docker Compose)
- Git
- Любой современный браузер

## Установка и запуск

### 1. Клонируйте репозиторий

```
git clone https://github.com/YkrasinNikita/collab-app.git
cd collab-app
```

### 2. Настройте переменные окружения

Создайте в папках `auth-service`, `documents-service`, `collaboration-service` файлы `.env`.

#### auth-service/.env

```
JWT_ACCESS_SECRET=ваш_секретный_ключ_1
JWT_REFRESH_SECRET=ваш_секретный_ключ_2
```

#### documents-service/.env

```
JWT_ACCESS_SECRET=ваш_секретный_ключ_1
```

#### collaboration-service/.env

```
JWT_ACCESS_SECRET=ваш_секретный_ключ_1
```

> **Важно:** `JWT_ACCESS_SECRET` должен быть одинаковым во всех трёх файлах.
>
> Используйте сложные ключи, например:
>
> ```
> openssl rand -hex 32
> ```

### 3. Запустите приложение

```
docker-compose up --build
```

При первом запуске будут загружены образы и собраны контейнеры. Дождитесь сообщений о готовности сервисов.

### 4. Откройте приложение

Перейдите в браузере по адресу:

```
http://localhost:3000
```

## Основные функции

### Аутентификация

- Регистрация и вход с JWT-токенами (Access + Refresh)
- Проверка доступности email в реальном времени

### Заметки

- Rich-text редактор
- Форматирование текста
- Списки и чек-листы
- Автосохранение

### Ментальные карты

- Визуальный редактор
- Добавление и удаление узлов
- Управление связями
- Inline-переименование элементов

### Совместная работа

- Приглашение пользователей
- Управление ролями:
  - Просмотр
  - Комментирование
  - Редактирование
- Принятие и отклонение приглашений

### Комментарии

- Комментирование документов

### Работа в реальном времени

Через Socket.IO:

- Изменения контента отображаются мгновенно
- Изменения заголовка отображаются мгновенно
- При удалении документа происходит автоматический переход на главную страницу
- При исключении пользователя из соавторов выполняется автоматический выход из документа

### Личный кабинет

- Изменение имени
- Изменение email с проверкой уникальности
- Смена пароля

### Дополнительно

- Тёмная и светлая темы
- Сохранение выбранной темы в `localStorage`
- Адаптивный дизайн

## Структура проекта

```
collab-app/
├── auth-service/           # Микросервис авторизации (Express + MongoDB)
├── documents-service/      # Микросервис документов и ментальных карт
├── collaboration-service/  # Микросервис прав доступа, комментариев и сокетов
├── frontend/               # Next.js приложение
├── docker-compose.yml      # Конфигурация Docker
└── .gitignore
```

## Порты

| Сервис | Порт |
|---------|------|
| Frontend | 3000 |
| Auth Service | 4001 |
| Documents Service | 4002 |
| Collaboration Service | 4003 |
| MongoDB | 27017 |

> MongoDB доступна только во внутренней сети Docker и не открыта наружу.

## Полезные команды

### Остановить все контейнеры

```
docker-compose down
```

### Пересобрать конкретный сервис

```
docker-compose build --no-cache frontend
```

### Просмотреть логи сервиса

```
docker-compose logs -f auth-service
```

### Очистить неиспользуемые Docker-ресурсы

```
docker system prune -a
```

## Примечания

- При разработке сервисы можно запускать локально без Docker, но потребуется запущенная MongoDB.
- Настроены ESLint и Prettier.
- Для логирования используется Pino:
  - В production выводится JSON.
  - В development используется цветной вывод.
- Все JWT-секреты должны храниться в `.env` файлах.
- Файлы `.env` добавлены в `.gitignore`, поэтому не попадают в репозиторий.
